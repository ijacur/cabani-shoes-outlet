# Публикация CABANI SHOES OUTLET на собственном домене

Эта сборка подготовлена для VPS или Node.js-хостинга с постоянным диском. Для SQLite обязательны постоянное хранение папки `data/` и резервные копии `data/` вместе с `public/uploads/`. Не используйте ephemeral/serverless filesystem.

## Что подготовлено в проекте

- Проверка production-переменных: приложение не запустится в production без `SESSION_SECRET` (минимум 32 символа), `ADMIN_USERNAME` и `ADMIN_PASSWORD` (минимум 14 символов) при первичном создании администратора.
- В production демо-товары автоматически не добавляются.
- Endpoint проверки работоспособности: `/healthz`.
- `.gitignore`, пример конфигурации PM2 и пример Nginx reverse proxy.
- Сессии используют Secure cookies при `NODE_ENV=production`.

## 1. Подготовить домен

У регистратора домена добавьте DNS-записи:

- `A` для `@` → публичный IPv4 вашего VPS.
- `CNAME` для `www` → корневой домен (или отдельную `A` запись на тот же IP).

DNS может обновляться не мгновенно. IP и точные записи зависят от выбранного хостинга.

## 2. Установить серверные компоненты (Ubuntu VPS)

Установите Node.js 20+, Nginx и PM2. Затем загрузите архив на сервер, распакуйте его в отдельную папку, например `/var/www/cabani`, и выполните:

```bash
cd /var/www/cabani
npm install --omit=dev
cp .env.example .env
nano .env
```

При первом развёртывании npm создаст `package-lock.json`; сохраните его в вашем приватном репозитории/архиве. В дальнейшем для повторяемых установок используйте `npm ci --omit=dev`.

Заполните `.env`:

```env
NODE_ENV=production
PORT=3000
TRUST_PROXY=1
SESSION_SECRET=ВСТАВЬТЕ_СЛУЧАЙНУЮ_СТРОКУ_МИНИМУМ_32_СИМВОЛА
ADMIN_USERNAME=ваш_логин
ADMIN_PASSWORD=ДЛИННЫЙ_УНИКАЛЬНЫЙ_ПАРОЛЬ_МИНИМУМ_14_СИМВОЛОВ
STORE_NAME=CABANI SHOES OUTLET
WHATSAPP_NUMBER=998XXXXXXXXX
TELEGRAM_BOT_TOKEN=
TELEGRAM_CHAT_ID=
```

Секреты храните только на сервере. Не отправляйте `.env` в чат, не добавляйте его в Git и не помещайте в `public/`.

Сгенерировать SESSION_SECRET можно командой:

```bash
openssl rand -base64 48
```

## 3. Запустить приложение через PM2

```bash
pm2 start ecosystem.config.cjs
pm2 save
pm2 startup
```

Выполните команду, которую напечатает `pm2 startup`. Проверьте локально:

```bash
curl http://127.0.0.1:3000/healthz
```

Ожидаемый ответ: `{"ok":true,"service":"cabani-shoes-outlet"}`.

## 4. Подключить Nginx и HTTPS

Скопируйте `deploy/nginx-cabani.conf.example` в `/etc/nginx/sites-available/cabani`, замените `shop.example.com` на ваш домен, включите конфигурацию и проверьте Nginx:

```bash
sudo ln -s /etc/nginx/sites-available/cabani /etc/nginx/sites-enabled/cabani
sudo nginx -t
sudo systemctl reload nginx
```

После того как DNS указывает на VPS, установите сертификат Let's Encrypt через Certbot для корневого домена и `www`. Затем включите автоматическое продление сертификата и проверьте сайт по HTTPS. Не передавайте платёжные данные через HTTP.

## 5. Первый запуск и проверка

1. Откройте `https://ВАШ-ДОМЕН/`.
2. Откройте `https://ВАШ-ДОМЕН/admin` и войдите с заданными `ADMIN_USERNAME` и `ADMIN_PASSWORD`.
3. Добавьте реальные товары, фотографии, цены и размеры. В production демонстрационный каталог не создаётся.
4. Проверьте заказ тестовым товаром и получение Telegram-уведомления (если заполнены Telegram-переменные).
5. Проверьте мобильную версию, контакты, доставку, политику конфиденциальности и условия возврата.
6. Сделайте резервную копию `data/` и `public/uploads/` и проверьте восстановление из неё.

## Важно перед публичным запуском

- Этот проект пока принимает заказы без онлайн-оплаты. Payme, CLICK и Uzum Bank не считаются подключёнными до отдельной реализации, ввода merchant credentials и тестирования callback/webhook.
- Не включайте реальную оплату, пока не проверены подписи callback, сумма, валюта, номер заказа и защита от повторной обработки платежей.
- Уточните с хостингом, что он поддерживает Node.js 20+, постоянный диск, SQLite/лучше отдельный managed DB при масштабировании, резервные копии и исходящие HTTPS-запросы Telegram.
- Перед публикацией проверьте юридические требования к интернет-торговле в Узбекистане и добавьте реквизиты продавца, правила доставки, обмена/возврата и политику обработки персональных данных.

## Что ещё нужно от владельца

Для точной настройки DNS и SSL нужны: сам домен (например, `cabani.uz`) и название хостинга/VPS-провайдера. Для фактической публикации также необходим доступ к панели DNS/хостинга либо выполнение приведённых команд владельцем сервера. Не отправляйте пароли, приватные SSH-ключи, токены бота или платёжные секреты в чат.
