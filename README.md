# CABANI SHOES OUTLET — магазин + админ-панель

Полноценный стартовый проект с сервером Node.js, SQLite, авторизацией администратора, загрузкой фото, управлением товарами и заказами.

## Что включено
- Публичный API каталога и создания заказа
- Админ-панель `/admin`
- Вход администратора с хешированием пароля
- Добавление, редактирование, скрытие и удаление товаров
- Загрузка фото на сервер (JPG/PNG/WEBP/AVIF до 5 МБ)
- Категории, цены, старая цена, размеры, описание
- Заказы: просмотр покупателя, телефона, состава, суммы, комментария и даты
- Статусы заказа: новый, подтверждён, в обработке, отправлен, завершён, отменён
- Сводные показатели магазина
- Смена пароля администратора
- SQLite база данных и серверные сессии
- Валидация заказа и цены на сервере

## Требования
- Node.js 20 или новее
- npm

## Установка на компьютере
1. Распакуйте архив.
2. Откройте папку проекта в терминале.
3. Установите зависимости:
   ```bash
   npm install
   ```
4. Скопируйте `.env.example` в `.env`.
5. Обязательно задайте уникальный `SESSION_SECRET`, логин и сложный пароль администратора.
6. Запустите:
   ```bash
   npm start
   ```
7. Магазин: `http://localhost:3000`
8. Админ-панель: `http://localhost:3000/admin`

Первый запуск создаст базу `data/cabani.sqlite`, таблицы и администратора из `.env`. Если переменные не изменены, будут применены временные данные `admin / ChangeThisPassword123!`. Не публикуйте сайт с этими значениями. Сразу смените пароль в админ-панели.

## Важно: подключение текущего дизайна магазина
Файлы старой статической витрины из предыдущего архива можно перенести/адаптировать, но для полной работы с динамическим каталогом витрина должна запрашивать `GET /api/store`, а оформление заказа — отправлять `POST /api/orders` с `name`, `phone`, `address`, `comment`, `items: [{productId, size, qty}]`.
Этот пакет включает API для этого, а файл `public/index.html` — базовую стартовую витрину, чтобы сервер запускался сразу.

## Перед публикацией
- Разместите проект на VPS/Node.js-хостинге с HTTPS.
- Заполните `.env` настоящими параметрами.
- Сделайте резервное копирование `data/cabani.sqlite` и `public/uploads/`.
- Не размещайте папки `data/` и `.env` в публичном доступе.
- Добавьте юридические условия, политику конфиденциальности, возврат и доставку.
- Подключите реальный платёжный провайдер и интеграцию доставки при необходимости.

## Ограничения текущей версии
Онлайн-оплата и интеграция курьерской службы не подключены. Заказы, созданные через API, сохраняются в SQLite и видны администратору. Для размещения нужен Node.js-хостинг; обычный статический хостинг не подойдёт.


## Уведомления о новых заказах в Telegram

При поступлении нового заказа сервер отправляет сообщение в Telegram с номером заказа, именем и телефоном покупателя, адресом (если указан), товарами, размерами, количеством, общей суммой и временем по Ташкенту. Если Telegram временно недоступен, заказ всё равно сохраняется в базе магазина.

### Настройка
1. В Telegram откройте `@BotFather`, отправьте `/newbot` и создайте бота. Сохраните выданный токен.
2. Откройте чат с новым ботом и нажмите **Start** (или отправьте `/start`).
3. Узнайте свой chat ID: откройте `https://api.telegram.org/botВАШ_ТОКЕН/getUpdates` в браузере после отправки `/start` боту. В ответе найдите `message.chat.id`.
4. В файле `.env` заполните:
   ```env
   TELEGRAM_BOT_TOKEN=токен_от_BotFather
   TELEGRAM_CHAT_ID=ваш_chat_id
   ```
5. Перезапустите сервер (`Ctrl+C`, затем `npm start`).
6. Оформите тестовый заказ на сайте и проверьте, что бот прислал уведомление.

**Безопасность:** не отправляйте токен бота посторонним, не публикуйте `.env` и не загружайте его в публичный репозиторий. Если токен случайно раскрыт, перевыпустите его через `@BotFather`.
